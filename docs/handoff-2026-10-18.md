## Hoe je dingen draait

**Tests tegen Postgres** (integratietests slaan zichzelf over zonder DSN):

```bash
docker run -d --name cortexiq-test-pg -e POSTGRES_USER=cortexiq -e POSTGRES_PASSWORD=cortexiq \
  -e POSTGRES_DB=cortexiq_test -p 55432:5432 pgvector/pgvector:pg16
export CORTEXIQ_TEST_DSN="postgres://cortexiq:cortexiq@localhost:55432/cortexiq_test?sslmode=disable"
go test ./internal/brain/ ./internal/queries/
docker rm -f cortexiq-test-pg
```

Docker Desktop moet draaien; start het zelf als `docker info` faalt.

**Eval op prod** zonder de service aan te raken. Het binary in de image heet
`/cortexiq` en staat niet in het PATH, de image bevat de `eval/`-map niet, en de
draaiende container kent nieuwe subcommando's pas na een rebuild. Daarom een tijdelijk
binary:

```bash
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -o <tmp>/cortexiq-eval ./cmd/cli
scp <tmp>/cortexiq-eval eval/graph_*.jsonl strato-vps:/tmp/
ssh strato-vps 'docker cp /tmp/cortexiq-eval cortexiq-cortexiq-1:/home/nonroot/ && \
  docker cp /tmp/graph_corpus.jsonl cortexiq-cortexiq-1:/home/nonroot/ && \
  docker cp /tmp/graph_queries.jsonl cortexiq-cortexiq-1:/home/nonroot/ && \
  docker exec cortexiq-cortexiq-1 /home/nonroot/cortexiq-eval eval graph \
    --corpus /home/nonroot/graph_corpus.jsonl --queries /home/nonroot/graph_queries.jsonl'
```

De container gebruikt zijn eigen omgeving (embedder, database), er worden geen
secrets gelezen of getoond. `eval graph` en `eval recall` schrijven tijdelijk naar een
`/eval/`-namespace en verwijderen die weer; controleer na afloop met
`SELECT count(*) FROM namespaces WHERE slug LIKE '/eval/graph-%'`.

De auto-mode-controle weigerde deze actie de eerste keer zonder uitleg; Bo heeft hem
daarna vrijgegeven. Vraag opnieuw om akkoord als dezelfde actie weer wordt geweigerd,
en omzeil het niet.

## Valkuilen in deze omgeving

- **Dubbele backslashes in heredocs worden samengevouwen** door de Bash-tool. Een
  SQL-template of Go-string met `\\` of `\n` komt dan stuk binnen. Schrijf zulke
  bestanden met de Write- of Edit-tool, niet met `cat <<EOF` of Python in een heredoc.
  Dit kostte hier twee keer een kapotte build.
- **Python (Windows) en Bash (msys) hebben een ander `/tmp`.** Een bestand dat Bash in
  `/tmp` schrijft, ziet Python niet. Gebruik `cygpath -w` of een pad in de scratchpad.
- **`go test ./...` meldt op Windows soms `unlinkat ... test.exe ... in gebruik`.**
  Dat is opruimruis van de tempmap, geen falende test; kijk naar de `FAIL`/`ok`-regels.
- **Een `.env` ontbreekt lokaal**: zonder `CORTEXIQ_*`-variabelen start de CLI niet
  (`load config: ... is not set`). Evals tegen een echte embedder draaien daarom op de
  server.
- **De Hindsight-referentie** (v0.9.2, bank `gaia`) staat op
  `http://100.65.0.15:9999/banks/gaia?view=home`, bereikbaar via Tailscale. Alleen
  bekeken, niets gewijzigd. Opvallend daar: 52% van de achtergrondoperaties staat op
  failed; dat staat los van CortexIQ.
